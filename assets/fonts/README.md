# Caption fonts

Bundled so burned-in captions look identical on every machine (FFmpeg/libass loads them via `fontsdir`, no system install needed).

| File | Family | License | Source |
|---|---|---|---|
| Montserrat-ExtraBold.ttf | Montserrat ExtraBold | SIL Open Font License 1.1 | https://github.com/JulietaUla/Montserrat |
| Montserrat-Black.ttf | Montserrat Black | SIL Open Font License 1.1 | https://github.com/JulietaUla/Montserrat |
| Anton-Regular.ttf | Anton | SIL Open Font License 1.1 | https://github.com/googlefonts/AntonFont |
| BebasNeue-Regular.ttf | Bebas Neue | SIL Open Font License 1.1 | https://github.com/dharmatype/Bebas-Neue |

`OFL.txt` contains the license text (identical terms for all four families; each family keeps its own copyright holders).
